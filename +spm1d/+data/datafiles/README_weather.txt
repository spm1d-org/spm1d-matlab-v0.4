Canadian weather dataset

"CanadianWeather.rda" is an unmodified copy of "data/CanadianWeather.rda"
from the R package "fda" (version 6.1.9) by James Ramsay, Giles Hooker and
Spencer Graves:
https://cran.r-project.org/package=fda
The "fda" package is distributed under the license "GPL (>= 2)".

"CanadianWeather.mat" is a conversion of
"CanadianWeather.rda" made on 17 November 2026. The values are unchanged.

The dataset is described in:
Ramsay JO, Silverman BW (2005). Functional Data Analysis
(Second Edition), Springer, New York.

"weather.mat" contains the daily temperatures from "CanadianWeather.mat"
separated by region (y0: Atlantic, y1: Pacific, y2: Continental, y3: Arctic)
and smoothed over days with a circular Gaussian kernel (standard deviation: 8 days).
